# 本文JUMP

教科書本文の家庭学習用アプリ(スマホ向け)。

- A しくみを見つける(文法レッスン)→ B 本文(音読 → 英→日 → 日→英＋音読)
- マイク判定は iPhone の Safari / Android の Chrome で動作
- 記録はブラウザ(localStorage)に保存

# 英単語クラフト（craft.html）

パソコン向けの英単語タイピングゲーム。`/craft.html` で開く。

## まちがい記録との同期（版 10/29-sync）

- 問題を解くたびに、結果（× まちがい／○ 正解）を Google スプレッドシート「拓真 英語まちがい記録」に送ります。
- 送れなかった分は端末にためておき、次に開いたときにまとめて送ります。マップ画面の下に「記録：送信ずみ／送信待ち ○件」と出ます。
- 送るのは種類・項目・答え・日時だけで、名前は送りません。
